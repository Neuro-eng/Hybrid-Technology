# AWS Certified Cloud Practitioner — Notes & Practice Exams

Free, community-maintained study notes and practice questions for the **AWS Certified Cloud Practitioner (CLF-C02)** exam.

**100% free — no signup, no payment required.**

## What's inside
- 📘 111 original practice questions across 10 domain-focused exams + a 65-question full-length mock exam → [`practice-exam/exams.md`](practice-exam/exams.md)
- 🧠 A diagnostic quiz to identify weak areas before you start
- 📄 A downloadable PDF version of everything, hosted directly in this repo (`assets/pdf/`)
- 📡 A live-updating AWS news ticker on the homepage
